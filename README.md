# skep-testing

A test repository for the Skep supervisor tool.

## Installation

Clone the repository and install dependencies:

```bash
git clone <repo-url>
cd skep-testing
pip install -r requirements.txt
```

## Usage

Run the calculator:

```bash
python calculator.py 5 + 3
```

Run the hello script:

```bash
python hello.py
```

Run tests:

```bash
pytest test_calculator.py
```

## Testing

This repository is exercised by Skep end-to-end tests.
