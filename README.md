# Advanced Calculator

A browser-based advanced calculator with multiple modes: Standard, Scientific, Unit Converter, Base Converter, Currency Converter, and Date Calculator.

## How to Open

Simply open `index.html` in any modern web browser. No server or build step required.

## Features

- **Standard Calculator**: Basic arithmetic (add, subtract, multiply, divide), percentage, sign toggle, decimal, backspace, clear.
- **Scientific Calculator**: Trigonometric functions (sin, cos, tan), logarithms (log, ln), square root, power (x^y), constants (π, e), factorial, and basic arithmetic.
- **Unit Converter**: Convert between units of length, temperature, weight, and volume.
- **Base Converter**: Convert numbers between binary (2), octal (8), decimal (10), and hexadecimal (16).
- **Currency Converter**: Convert between USD, EUR, GBP, JPY, CNY using static exchange rates.
- **Date Calculator**: Calculate the difference between two dates in days, hours, and minutes.
- **Theme Toggle**: Switch between light and dark themes.
- **Accessibility**: ARIA labels, keyboard navigation (arrow keys to switch tabs), and responsive design.

## Technologies

- HTML5
- CSS3 (CSS variables, responsive design)
- Vanilla JavaScript (no frameworks)
